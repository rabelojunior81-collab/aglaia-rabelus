**Registro:** 2026-10-24 · **Classe:** proveniência · **Estado:** fundação inicial; linhagem histórica parcialmente atribuída.

## Origem do projeto

O Pai Adilson iniciou Aglaia Studio como direção de produto para um estúdio local de edição/composição/geração de Reels de joias, usando coleções de fotos multiângulo e vídeos 360 existentes. Ele definiu publicação pública full open source e propósito didático para alunos. Este registro deriva de briefing verbal fornecido pelo Pai; não declara ser a primeira origem da ideia nem substitui material original ainda não incorporado.

## Crédito e limites

O Rabelus Matrix Protocol é a camada comum proposta para registros de sessão, proveniência, claims e verificação, com adapters por harness. O nome do protocolo não renomeia o produto Aglaia Studio. Esta fundação foi escrita para Aglaia e não copia código, corpus/persona CLI Buddy, transcrições privadas, caminhos de host, mídia comercial, segredos ou configuração pessoal. Não se atribui autoria de componentes herdados sem fonte correspondente. Correções futuras devem acrescentar proveniência e preservar versões publicadas.
