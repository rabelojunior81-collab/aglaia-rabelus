# ADR-0001: fundação e licença inicial

- **Estado:** aceita para a Fase 0 pelo responsável do produto.
- **Data:** 2026-10-24.

## Contexto

O repo precisa começar público, didático e open source, com termos claros para contribuições e redistribuição.

## Decisão

Usar Apache License 2.0 para os artefatos originais desta fundação. É licença permissiva conhecida, inclui concessão expressa de patente e preserva NOTICE e avisos de alteração; é adequada à documentação e aos verificadores pequenos sem adotar dependência de framework. Registrar atribuições no NOTICE. A licença não concede direitos sobre marcas ou mídia comercial de terceiros.

## Consequências

Reavaliar dependências e compatibilidade antes de adicionar código de candidatos. Cada contribuição precisa de origem/licença clara. A decisão vale para a fundação e não afirma que qualquer biblioteca futura seja compatível.
