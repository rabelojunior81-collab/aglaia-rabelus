# Adapters

Estado inicial: apenas documentação. Um adapter só pode ser marcado ativo depois de ensaio reproduzível no harness e ambiente declarados, evidência de acionamento e limites. Nenhum arquivo desta pasta deve ser instalado automaticamente. Codex, Claude e futuros harnesses são adapters pares; o desenvolvimento intencionalmente centrado em Claude no Buddy não permite inferir dependência exclusiva.
