# Aglaia Rabelus

**Aglaia Studio** is a local desktop studio, Mac first, in its foundation phase. Its initial direction is to help compose jewelry reels from existing multi-angle photo collections and rotation videos. The editor has not been implemented and no technology stack has been selected.

This is a public full open source project, also intended as educational material for the author's students. This foundation contains no commercial media, credentials, personal configuration, or private transcripts.

## Status

Phase 0 covers provenance, product brief, governance, and initial verifiers. Tool research is recorded; Remotion, HyperFrames, Higgsfield, and other candidates remain unselected and untested in this repository. No paid API, subscription, or model credit is used or assumed to be free.

## Principles

- Organization is beautiful.
- Before, during, and after, always.
- Each is one; all are one.
- Evidence before claims. Distinguish documentation, configuration, local tests, harness trials, and human acceptance.
- Every rule must point to a verifiable mechanism or be identified as human conduct.
- Routine decisions may be autonomous within a phase envelope; decisions outside it stop for review.
