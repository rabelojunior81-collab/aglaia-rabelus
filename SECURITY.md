# Segurança

Não publique segredos, tokens, credenciais, configurações pessoais, mídia comercial, dados de clientes ou transcrições privadas. Reporte vulnerabilidades de forma privada ao mantenedor do GitHub do projeto; não abra issue pública com detalhes exploráveis.

Os verificadores desta fase são ferramentas locais cooperativas. Eles não são sandbox, proteção contra processo malicioso, autenticador de identidade, lock distribuído, nem substituto de revisão humana. Não use o repositório como armazenamento de segredos ou originais de mídia.
